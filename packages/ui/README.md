# UI Package

## Responsibility

Reusable UI components for frontend apps.

## Owns

- Button, input, form, table, modal, layout, chart primitives.
- Theme tokens.
- Accessibility utilities.

## Allowed

- Framework-specific UI if standardized for apps.
- Storybook/examples if needed.

## Forbidden

- API calls.
- Auth/session logic.
- Business logic for memory, retrieval, connectors, or billing.
